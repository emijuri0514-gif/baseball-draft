## 0. プロジェクト概要

- サイト：https://dreamteam9.com/
- 内容：現役NPB選手をAI球団と取り合うドラフト会議シミュレーション＋スタメン編成＋試合シミュレーション
- 周辺ページ：遊び方、攻略、用語集、FAQ、選手名鑑、球団紹介、ランキング、歴代ドラフト伝説、2026ドラフト特集、野球くじ(β)、おすすめグッズ、中継サブスク比較、球団別中継ガイド、開発ブログ、更新履歴
- 公開：2026年8月末ごろ
- 現状：月間アクティブユーザー 約879、イベント数 約12万（1人あたり約136イベント）
- 収益：0円（AdSense未合格、アフィリエイトはスカパー！・楽天・Amazonのみ設置）
- 目標：月間収益10万円（本命は2027年3〜4月のプロ野球開幕期）

## 1. 基本方針

- ゲームは「集客装置」、収益の主軸は「中継サブスク系アフィリエイト」
- 季節性に合わせてCTA（収益導線）を切り替える
- 2026年10月22日（木）のドラフト会議が年間最大の集客機会
- 権利リスクの解消を最優先する（収益化の前提条件）

## 2. 収益モデル（仮定値）

| 収益源 | 前提 | 月額 |
|---|---|---|
| 中継サブスク系アフィリエイト | 記事3万PV × CTAクリック率5% × 成約率2% = 30件 × 単価2,000円 | 60,000円 |
| AdSense | 10万PV × RPM 200円 | 20,000円 |
| 物販・旅行アフィリエイト | 楽天・Amazon・宿泊 | 10,000円 |
| 支援・有料機能 | 50人 × 300円 | 15,000円 |
| 合計 | | 約105,000円 |

| 時期 | 目標月収 |

## 3. 実装ルール

- 既存の機能・デザインを壊さないこと。変更前に該当箇所を確認し、変更は最小単位で行う
- 選手写真、球団ロゴ、公式ユニフォーム画像は使用しない（球団カラーの使用のみ可）
- アマチュア選手（特に高校生）には能力値・数値評価を付けない
- 野球くじ・交換ショップは、現金や換金性のある景品と結びつけない
- アフィリエイトリンクには必ず「PR」表記を付ける
- 外部リンク（アフィリエイト）には `rel="sponsored noopener"` を付与
- 法的判断が必要な変更（能力値算出ロジックの差し替えなど）は、方針案を提示してオーナーの確認を取ってから実装する
- 作業ごとに更新履歴ページ（changelog.html）へ追記する
