# 独自能力値算出用CSV仕様（T0-1）

`docs/STAT_FORMULA_DESIGN.md`で提案した変換式に読み込ませるためのCSV仕様。
打者用・投手用の2つのCSVファイルを用意する。

## 突合キー（既存選手データとの紐付け方法）

- 各行の `id` 列に、`index.html`の`initialDatabase`に登録済みの選手IDをそのまま入れる。
  このIDは週刊ベースボールONLINE（`sp.baseball.findfriends.jp`）の実在の選手ページIDで、
  既存データと1対1で対応する（CLAUDE.mdに記載の既存ルールと同じ）。
- `id`が`initialDatabase`に存在しない選手の行は、今回の変換では**スキップ**する
  （新人選手を新規追加する場合は別途相談。まずは既存選手の数値差し替えのみを対象とする）。
- `name`列は目視確認用（IDの入力ミスがないかのダブルチェック）。実際の突合には使わない。

## 1. 打者用CSV（例：`batters_2025.csv`）

### ヘッダー行と記入例

```csv
id,name,team,pa,avg,obp,slg,hr,sb,primary_pos,g,sb_pct,fld_pct,farm_pa,farm_avg,farm_obp,farm_slg
19960043,岸田行倫,巨人,240,.235,.301,.320,4,0,捕,88,,.992,,,,
19990197,泉口友汰,巨人,520,.280,.345,.410,10,15,二,128,0.83,.985,,,,
```

### 列の説明

| 列名 | 必須/任意 | 内容 |
|---|---|---|
| `id` | **必須** | 既存選手データのID（突合キー） |
| `name` | **必須** | 選手名（確認用） |
| `team` | 任意 | 所属球団（確認用。既存データの`team`は変更しない） |
| `pa` | **必須** | シーズン打席数（規定到達判定・縮小推定の重みに使用） |
| `avg` | **必須** | 打率（例：`.280`） |
| `obp` | **必須** | 出塁率 |
| `slg` | **必須** | 長打率 |
| `hr` | **必須** | 本塁打数 |
| `sb` | **必須** | 盗塁数 |
| `primary_pos` | **必須** | 主に守るポジション（捕・一・二・三・遊・左・中・右・DHのいずれか） |
| `g` | 任意 | 出場試合数（参考値） |
| `sb_pct` | 任意 | 盗塁成功率（0〜1の小数）。あれば走力の精度が上がる |
| `fld_pct` | 任意 | 守備率（0〜1の小数）。あれば同ポジション内での守備補正に使う |
| `farm_pa`〜`farm_slg` | 任意 | 二軍（ファーム）成績。一軍`pa`が少ない選手（新人・故障明けなど）の縮小推定に使用 |

**規定打席未満の選手**（`pa`が規定打席の目安を下回る場合）は`farm_*`列があれば優先的に使う。
無い場合は一軍成績とリーグ平均の加重平均（縮小推定）で扱うため、`pa`が少なくても行自体は必ず提出すること
（空欄にせず、少ない打席数のまま実際の成績を入れる）。

## 2. 投手用CSV（例：`pitchers_2025.csv`）

### ヘッダー行と記入例

```csv
id,name,team,role,g,gs,ip,era,whip,k9,bb9,sv,farm_ip,farm_era,farm_k9,farm_bb9
20000044,戸郷翔征,巨人,先発,26,26,180.1,2.85,1.05,8.2,2.1,,,,,
19960048,ライデル・マルティネス,巨人,抑え,58,0,58.0,1.80,0.95,11.0,2.5,42,,,,
```

### 列の説明

| 列名 | 必須/任意 | 内容 |
|---|---|---|
| `id` | **必須** | 既存選手データのID（突合キー） |
| `name` | **必須** | 選手名（確認用） |
| `team` | 任意 | 所属球団（確認用） |
| `role` | **必須** | `先発` / `中継` / `抑え` のいずれか（既存の`bestPos`表記に合わせる） |
| `g` | **必須** | 登板数 |
| `gs` | 任意 | 先発登板数（先発投手のスタミナ算出の精度が上がる） |
| `ip` | **必須** | 投球回（例：`180.1`は180回1/3のNPB表記のまま） |
| `era` | **必須** | 防御率（算出結果の妥当性チェック用） |
| `whip` | **必須** | WHIP（算出結果の妥当性チェック用） |
| `k9` | **必須** | 奪三振率（9イニングあたり） |
| `bb9` | **必須** | 与四球率（9イニングあたり） |
| `sv` | 任意 | セーブ数（抑え投手の役割確認用） |
| `farm_ip`〜`farm_bb9` | 任意 | 二軍成績。一軍`ip`が少ない投手の縮小推定に使用 |

## 3. 共通の注意点

- 数値はすべて半角。打率・出塁率・長打率は`.280`のように小数点から書いても`0.280`でもどちらでも構いません
  （変換スクリプト側で吸収します）。
- 空欄でよい任意項目は、列自体は残したまま値だけ空にしてください（列を削除しないでください）。
- 1シーズン分＝1ファイルを想定しています。複数年分をまとめて送る場合は`year`列の追加を別途相談してください。
- ファイル形式はCSV（UTF-8、カンマ区切り、1行目はヘッダー）でお願いします。Excelから保存する場合は
  「CSV UTF-8（コンマ区切り）」形式を選んでください。

## 4. 提出後の流れ

1. オーナーからCSV2ファイル（打者用・投手用）を受け取る
2. `id`が`initialDatabase`に存在するかを機械的にチェックし、一致しない行があれば先に確認を返す
3. 変換スクリプトで`fStats`/`pStats`を試算し、現行値との比較表（20人程度）を作成して報告
4. 問題なければ`initialDatabase`を一括更新

目標受領日：2026年10月5日ごろ。
