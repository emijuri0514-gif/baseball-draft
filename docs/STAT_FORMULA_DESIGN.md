# 独自能力値算出式 設計案（T0-1）

> ROADMAP.md T0-1「権利リスク対応」に基づく設計提案。**この文書はコード実装を含まない。**
> 内容の承認後に変換スクリプトを実装し、切り替えと同時にfaq.html / privacy.html / recommend.htmlの
> 「プロスピAの数値をそのまま使用」という記載を修正する（changelog.html / devblog.htmlは書き換えない）。

---

## 1. 目的とスコープ

現在`index.html`の`initialDatabase`にある能力値（ミート・パワー・走力・守備、投手の球威・制球・スタミナ）は
「プロ野球スピリッツA」のカード数値をそのまま転記したもので、権利上のリスクがある。
これをNPB公式の個人成績から独自に算出した値に置き換える。

対象となる能力値と現在のデータ形式：

```js
// 野手
{ fStats: { meet: 数値, pow: 数値, run: 数値, def: 数値 } }
// 投手
{ pStats: { pow: 数値, con: 数値, sta: 数値 } }  // pow=球威, con=制球, sta=スタミナ
```

現在ゲーム内に存在する実測レンジ（`initialDatabase`から集計、n=125打者・n=106投手）：

| 能力 | 最小 | 最大 | 平均 |
|---|---|---|---|
| meet（ミート） | 50 | 81 | 70.2 |
| pow（パワー） | 50 | 84 | 70.1 |
| run（走力） | 50 | 87 | 71.3 |
| def（守備） | 45 | 83 | 62.8 |
| pStats.pow（球威） | 50 | 85 | 75.5 |
| pStats.con（制球） | 50 | 86 | 72.2 |
| pStats.sta（スタミナ） | 50 | 81 | 69.2 |

新しい算出式は、この現行レンジ・分布感（下限50前後、平均67〜75、上限80〜90弱）を
概ね維持するように正規化する。これは「独自算出に切り替えたら急に評価がインフレ／デフレした」
という違和感を避けるため。

## 2. 入力データ

| 対象 | 入力項目 |
|---|---|
| 打者 | 打率、出塁率、長打率、本塁打、盗塁、守備位置（主に守るポジション） |
| 投手 | 防御率、WHIP、奪三振率（K/9）、与四球率（BB/9）、投球回、登板数 |

これらはすべてNPB公式が発表する基本的な成績で、算出過程も公開できる（＝権利上のグレーゾーンがない）。

## 3. データの取得方法

- **オーナーがCSVを用意**し、それを選手データのJSONに変換するスクリプト（Node.jsを想定）を新規作成する。
- npb.jpからの自動スクレイピングは、利用規約を確認できるまで行わない（T0-1の前提どおり）。
- CSVの列イメージ：

```csv
id,name,team,team_ja,avg,obp,slg,hr,sb,primary_pos,g,pa
19960043,岸田行倫,giants,巨人,.235,.301,.320,4,0,捕,88,240
```

```csv
id,name,team,team_ja,era,whip,k9,bb9,ip,g,role
20000044,戸郷翔征,giants,巨人,2.85,1.05,8.2,2.1,180.1,26,先発
```

- 変換スクリプトは `initialDatabase`の`id`（週刊ベースボールONLINEの選手ページID、CLAUDE.md記載の既存ルール）を
  そのままキーに使い、既存選手データの`fStats`/`pStats`だけを置き換える（`name`/`team`/`bestPos`等は変更しない）。

## 4. 各能力への換算式

### 4.1 打者

| 能力 | 主な入力 | 考え方 |
|---|---|---|
| ミート | 打率 70% + 出塁率 30% | 打率は純粋な「当てる力」、出塁率を少し混ぜて四球選球眼も反映 |
| パワー | 長打率 60% + 本塁打（規定打席あたり換算） 40% | 長打率だけだと三塁打の多い選手が過大評価されるためHRも加味 |
| 走力 | 盗塁数（規定打席あたり換算） 100% | 盗塁企図数・成功率まで公式CSVに含められる場合は成功率で補正 |
| 守備 | 主守備位置の希少性ベース値 ± 補正 | 4.2節で詳細 |

各項目は「その年の規定打席到達者内での百分位（パーセンタイル）」を求め、下記の正規化（5節）で
現行レンジに当てはめる。

### 4.2 守備力の扱い（注意点）

公式の基本成績には守備の質を表す指標（守備率・失策数程度）しかなく、範囲や肩の強さは含まれない。
そのため守備力は次の簡易モデルにする：

1. 主守備位置ごとにベース値を設定する（希少性が高いポジションほど高め）。
   例：捕手・遊撃手・三塁手・中堅手 > 二塁手・右左翼手 > 一塁手・指名打者
2. 同じポジションを守る選手同士は「守備率（1-失策率）」の百分位で±10点程度の範囲で上下させる。
3. 一塁手やDH専任の選手は守備をほぼ評価しない（現行の`DEF_PRIORITY`のDH優先ロジックと整合させる）。

これは実際の守備範囲や肩の強さを正確に反映するものではないが、「捕手・遊撃手は守備が評価されやすく、
一塁手・DHは打撃力が評価の中心になる」という現在のゲームバランスの前提を壊さずに済む。
より精緻な守備指標（UZR等）が将来入手できるなら差し替え可能な形にしておく。

### 4.3 投手

| 能力 | 主な入力 | 考え方 |
|---|---|---|
| 球威 | 奪三振率（K/9） | 単純に「空振りを取れるか」を反映。等級付けはリーグ内百分位 |
| 制球 | 与四球率（BB/9）を反転（低いほど高評価） | 与四球率が低いほど制球が良いとみなす |
| スタミナ | 1試合あたり投球回（先発） or 登板数・連投耐性（救援） | 役割（先発/中継ぎ/抑え）によって計算対象を分ける |

先発投手は「登板1回あたりの平均投球回」を、救援投手は「シーズン登板数（規定投球回に対する比率）」を
スタミナの入力にする。役割は`bestPos`（先発／中継／抑え）から判定する。

防御率・WHIPは個々の能力値には直接使わず、算出結果の**妥当性チェック**に使う
（防御率が良いのに球威・制球・スタミナの合成値が低く出た投手がいないか等を目視確認する）。

## 5. 正規化方法

1. その年のNPB全体（両リーグ・規定到達者）を母集団とし、各入力指標のパーセンタイル順位を求める。
2. パーセンタイル（0〜100）を、各能力ごとに現行レンジ表（1節）の[低い方の実測値, 高い方の実測値]へ
   線形に写像する。例：ミートなら `50 + percentile/100 * (81-50)`。
3. レンジは今後、新しい選手データが増えるたびに`initialDatabase`から再集計して更新する
   （ハードコードした固定レンジにはしない）。

```js
function toGameScale(percentile, range) {
  const { low, high } = range; // 例: { low: 50, high: 81 }
  return Math.round(low + (percentile / 100) * (high - low));
}
```

## 6. 一軍出場が少ない選手・新人の扱い

- **規定打席／規定投球回に到達している選手**：そのまま4節の式で算出。
- **一軍出場はあるが規定未満の選手**：一軍成績とリーグ平均を打席数（またはイニング数）で加重平均する
  「縮小推定（shrinkage）」を使い、サンプルが少ないほどリーグ平均に近づける。

  ```
  推定値 = (本人の成績 × 本人のPA + リーグ平均 × K) / (本人のPA + K)
  ```
  `K`は「この打席数を打って初めて本人の成績を7割信用する」という目安の定数（例：200打席、投手は50イニング）。

- **一軍出場がほぼない新人・育成選手**：二軍（ファーム）成績があればそれを同様に縮小推定で使う。
  二軍成績も無い場合は、ドラフト時の評価（`eval`欄の役割表記）に応じた位置別の下限〜平均やや下の
  デフォルト値を仮置きし、翌シーズンの成績が出た時点で更新する。

## 7. 主要選手の比較イメージ（サンプル値・要確認）

以下は算出方法の動作イメージを示すための**架空の入力例**であり、実在選手の2025年公式成績の正確な転記ではない。
オーナーから実際の成績CSVを受け取り次第、この表を実データで差し替えて再報告する。

| 選手（例） | 入力例（打率/出塁率/長打率/HR/盗塁） | 現行プロスピA値（ミート/パワー/走力/守備） | 独自算出イメージ（同順） |
|---|---|---|---|
| 長距離砲タイプの一塁手 | .280 / .360 / .560 / 35本 / 2 | 75 / 82 / 55 / 60 | 74 / 80 / 56 / 51 |
| 巧打・俊足の遊撃手 | .310 / .370 / .420 / 8本 / 25 | 78 / 65 / 80 / 70 | 80 / 66 / 82 / 74 |
| 堅守型の捕手 | .245 / .310 / .350 / 10本 / 1 | 64 / 66 / 58 / 78 | 62 / 64 / 57 / 76 |
| エース級の先発投手 | 防御率2.10 / WHIP0.98 / K9 9.5 / BB9 1.8 / 180回 | 球威85 / 制球80 / スタミナ78 | 球威83 / 制球82 / スタミナ76 |
| 抑え投手 | 防御率1.80 / WHIP0.95 / K9 11.0 / BB9 2.5 / 55回・50登板 | 球威88 / 制球75 / スタミナ60 | 球威89 / 制球73 / スタミナ58 |

**実データ反映後にやること**：初期のリストアップ対象として、両リーグの主軸打者・エース級投手・抑え投手を
中心に20人程度（在籍球団に偏りが出ないよう各球団1〜2名を目安に選定）を並べ、上記と同じ形式の表を作成し、
現行値との乖離が大きい選手（±15点以上動く選手）については個別に妥当性を確認する。
